# Roadmap

Ideas worked out into future versions.

The public roadmap stays at the repository root, [roadmap.md](../../roadmap.md): the list of open work. Links from outside this folder (the GitHub issues of this repository among them) point to it, so it is not moved here.

When items from it are scheduled for a version, `docs/roadmap/<version>.md` lists them, and each item gets a plan in [plans/](../plans/). No version is scheduled yet.
