# Postmortem

Attempts that did not help, kept for history. Each entry names the problem (linked to its open issue), what was tried and the negative result, so the next session does not repeat the same attempt. No entries yet.

## Format

One file per attempt, `<topic>.md`:

```markdown
# <Attempt>

## Problem

<The problem, with a link to the open issue in ../open-issues/ or on GitHub.>

## What was tried

<The approach, the branch or commit if it exists.>

## Result

<Why it did not work: the error, the measurement, the side effect.>

## Lesson

<What to do instead, or what to check before trying again.>
```
